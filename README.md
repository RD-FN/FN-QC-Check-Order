# QC เช็คสินค้าก่อนจัดส่ง

เว็บสำหรับทีม QC ใช้ตรวจสินค้าออนไลน์ก่อนแพ็กส่งลูกค้า ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

- เช็ครายการสินค้าตามออร์เดอร์ พร้อมเวลาที่เช็คแต่ละรายการ
- บันทึกวันที่และเวลาตรวจอัตโนมัติ
- แนบรูปก่อนจัดส่ง (ระบบประทับวันเวลาบนรูปให้)
- เซ็นลายเซ็นผู้ตรวจบนหน้าจอ
- นำเข้ารายการสินค้าจาก CSV / Excel
- บันทึกผลตรวจลง **Google Sheets** และเก็บรูปกับลายเซ็นใน **Google Drive**
- แสดงเลขเวอร์ชันที่หัวเว็บ กดดูประวัติการอัปเดตได้
- แสดง **รูปสินค้า** ในรายการเช็ค (แนบรูปในหน้าเว็บ หรือใส่ลิงก์รูปในไฟล์ CSV / Excel)
- ช่องทางการขาย: Shopee, Makro PRO, LINE OA, Facebook, เว็บไซต์, หน้าร้าน และ "อื่นๆ" (ต้องระบุชื่อช่องทาง)
- เลือกบริษัทขนส่ง (Flash, J&T, KEX, ไปรษณีย์ไทย, SPX ฯลฯ) คู่กับเลขพัสดุ
- ต้องใส่ **รหัสผู้ดูแล** ก่อนนำเข้า/เพิ่ม/ลบรายการสินค้า และก่อนลบบันทึกผลตรวจ (เลือกลบได้หลายรายการที่หน้า ประวัติ > ลบข้อมูล)

**เปิดใช้งาน:** https://rd-fn.github.io/FN-QC-Check-Order/

เวอร์ชันปัจจุบัน: **1.5.0** (ดู [CHANGELOG.md](CHANGELOG.md))

## ระบบที่ตั้งค่าไว้แล้ว

- Google Sheet: **QC เช็คสินค้าก่อนจัดส่ง - ข้อมูล** (อยู่ใน Google Drive ของผู้ดูแลระบบ)
- Apps Script: **QC Check Backend** (Deploy เป็น Web app, ผู้มีสิทธิ์เข้าถึง: ทุกคน) ลิงก์อยู่ใน `config.js`
- GitHub Pages: branch `main` / root

## รหัสผู้ดูแล (ADMIN_PIN)

รหัสเก็บไว้ที่ Apps Script เท่านั้น ไม่ได้อยู่ในโค้ดเว็บ (repo นี้เป็นสาธารณะ)

- ตั้งหรือเปลี่ยนรหัส: เปิดโปรเจกต์ Apps Script > **การตั้งค่าโครงการ (ไอคอนเฟือง)** > **พร็อพเพอร์ตี้ของสคริปต์** > แก้ค่า `ADMIN_PIN` > บันทึก (ไม่ต้อง Deploy ใหม่)
- ใส่รหัสผิดเกิน 5 ครั้งใน 10 นาที ระบบจะล็อก 10 นาที
- ถ้ายังไม่ได้ตั้ง `ADMIN_PIN` จะนำเข้า/แก้ไขรายการสินค้าไม่ได้เลย
- ปลดล็อกแล้วจะใช้ได้จนปิดแท็บ หรือกดปุ่ม "ล็อก"

ขั้นตอนด้านล่างใช้เมื่อต้องตั้งค่าใหม่ทั้งหมด

## ขั้นที่ 1: ตั้งค่า Google Sheets (ทำครั้งเดียว)

1. สร้าง Google Sheet ใหม่ แล้วคัดลอก ID จากลิงก์ชีต (ส่วนระหว่าง `/d/` กับ `/edit`)
2. ไปที่ https://script.google.com สร้างโปรเจกต์ใหม่ แล้ววางเนื้อหาจาก `apps-script/Code.gs`
3. แก้บรรทัด `const SHEET_ID = '...'` ให้เป็น ID ของชีตใหม่
4. ตั้งรหัสผู้ดูแลใน **การตั้งค่าโครงการ > พร็อพเพอร์ตี้ของสคริปต์** ชื่อ `ADMIN_PIN`
5. (ไม่บังคับ) ตั้งรหัสลับที่บรรทัด `const API_KEY = '';` เช่น `'qc-2026-xyz'`
6. กดบันทึก แล้วเลือกฟังก์ชัน `setup` และกด **เรียกใช้ (Run)** ครั้งหนึ่ง
   - Google จะขออนุญาตเข้าถึงชีตและ Drive ให้กดอนุญาต
   - ระบบจะสร้างชีต `QC_Records`, `QC_Items`, `Products` และโฟลเดอร์ `QC Photos` ใน Drive
7. กด **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
8. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

> ทุกครั้งที่แก้ `Code.gs` ต้อง Deploy ใหม่: **จัดการการทำให้ใช้งานได้ > แก้ไข (ไอคอนดินสอ) > เวอร์ชัน: เวอร์ชันใหม่** URL จะคงเดิม

## ขั้นที่ 2: ใส่ลิงก์ในเว็บ

เปิด `config.js` แล้ววาง URL:

```js
window.QC_CONFIG = {
  SHEETS_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
  API_KEY: ""   // ใส่ให้ตรงกับ Code.gs ถ้าตั้งไว้
};
```

ถ้าเว้น `SHEETS_URL` ว่าง เว็บจะเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น (ใช้ทดลองได้)

## ขั้นที่ 3: เอาขึ้นเว็บ

เลือกทางใดทางหนึ่ง:

- **GitHub Pages:** push โฟลเดอร์นี้ขึ้น GitHub แล้วไปที่ **Settings > Pages > Deploy from a branch > main / (root)**
- **เซิร์ฟเวอร์ของบริษัท:** อัปโหลด `index.html`, `config.js` และโฟลเดอร์ `assets/` หรือรัน `python3 tools/build-single.py` เพื่อได้ไฟล์เดียว `dist/qc-check.html`

เว็บต้องเปิดผ่าน `https://` เพื่อให้กล้องมือถือและการส่งข้อมูลไป Google ทำงานได้ดี

## ข้อมูลที่ได้ใน Google Sheets

| ชีต | เนื้อหา |
|---|---|
| `QC_Records` | 1 แถวต่อ 1 การตรวจ: รหัสบันทึก, วันที่, เวลา, เลขออร์เดอร์, ช่องทาง, ลูกค้า, ขนส่ง, เลขพัสดุ, ผู้ตรวจ, สถานะ, รายการสินค้า, ลิงก์รูป, ลิงก์ลายเซ็น, เวอร์ชันเว็บ ฯลฯ (5 คอลัมน์สุดท้ายเป็นข้อมูลสำหรับระบบ ถูกซ่อนไว้ ห้ามลบ) |
| `QC_Items` | 1 แถวต่อ 1 สินค้าที่เช็ค เหมาะสำหรับทำ Pivot / สรุปยอด |
| `Products` | รายการสินค้า: รหัสสินค้า, ชื่อสินค้า, จำนวน, หน่วย, เลขออร์เดอร์, หมวดหมู่, รูปสินค้า (ลิงก์) แก้ในชีตได้โดยตรง หรือนำเข้าจากหน้าเว็บ |

รูปและลายเซ็นเก็บใน Google Drive โฟลเดอร์ `QC Photos/<วันที่>/` ส่วนรูปสินค้าเก็บที่ `QC Photos/สินค้า/`

## การนำเข้ารายการสินค้า

หน้า **รายการสินค้า** รับไฟล์ `.csv`, `.xlsx`, `.xls` แถวแรกเป็นหัวคอลัมน์ ระบบจับชื่อคอลัมน์ไทย/อังกฤษให้อัตโนมัติ ดูตัวอย่างที่ `sample/products-template.csv` (ต้องปลดล็อกด้วยรหัสผู้ดูแลก่อน)

**รูปสินค้า** ใส่ได้ 2 วิธี: กดปุ่ม "เพิ่มรูป" ข้างสินค้าแต่ละรายการ (รูปจะอัปโหลดไป Google Drive ให้) หรือใส่ลิงก์รูปในคอลัมน์ `รูปสินค้า` ของไฟล์ (ใช้ลิงก์ Google Drive ที่แชร์แบบ "ทุกคนที่มีลิงก์" ได้)

ถ้ามีคอลัมน์ **เลขออร์เดอร์** ตอนตรวจให้เลือกเลขออร์เดอร์ ระบบจะแสดงเฉพาะสินค้าของออร์เดอร์นั้นและบอกว่าเช็คครบหรือไม่

## การอัปเดตเวอร์ชัน

เมื่อแก้ไขเว็บ ให้แก้ใน `assets/app.js`:

1. เปลี่ยน `const APP_VERSION = "1.5.0";`
2. เพิ่มรายการใหม่ไว้บนสุดของ `CHANGELOG` (ข้อความนี้จะแสดงเมื่อกดเลขเวอร์ชันบนเว็บ)
3. บันทึกใน `CHANGELOG.md`
4. push ขึ้น GitHub แล้วหน้าเว็บจะอัปเดตเองใน 1-2 นาที

หลักการตั้งเลข: `หลัก.รอง.แก้ไข` เช่น แก้คำผิด 1.5.0 → 1.5.1, เพิ่มฟีเจอร์ 1.5.0 → 1.6.0

## ข้อควรรู้

- Web app ตั้งเป็น "ทุกคน" เพื่อให้เว็บส่งข้อมูลได้โดยไม่ต้องล็อกอิน การบันทึกผลตรวจไม่ต้องใช้รหัส แต่การแก้รายการสินค้าและการลบบันทึกต้องใช้รหัสผู้ดูแล
- ถ้า Google Workspace ของบริษัทไม่อนุญาตให้แชร์ไฟล์แบบ "ทุกคนที่มีลิงก์" รูปในหน้าประวัติจะแสดงเฉพาะคนที่ล็อกอินบัญชีที่มีสิทธิ์ (ลิงก์ในชีตยังใช้ได้ตามปกติ)
- ถ้าส่งไป Google Sheets ไม่สำเร็จ ข้อมูลในฟอร์มจะยังอยู่ กดบันทึกใหม่ได้ ระบบกันบันทึกซ้ำให้
